# Contact Tab - Edit Phone

---

## TC75 — Client > Edit > Contact tab > Phone > "Edit" button opens "Phone" window

| Step | Expected Result |
|------|-----------------|
| Log into RMSys as Administrator / Office Manager / RMSys Operator / Staffing Manager | User successfully logs into RMSys |
| Select any Client and click "Edit" button | "Edit Client" window opens |
| Click "Contact" tab | Contact tab opens |
| Locate "Phone" section | Phone section is displayed in the Contact tab |
| Select a phone record from the Phone List and click "Edit" button | "Phone" window opens with fields pre-filled with selected phone data |
