# Contact Tab - Delete Phone

---

## TC81 — Client > Edit > Contact tab > Phone > "Delete" button opens confirmation dialog

| Step | Expected Result |
|------|-----------------|
| Log into RMSys as Administrator | User successfully logs into RMSys |
| Select any Client and click "Edit" button | "Edit Client" window opens |
| Click "Contact" tab | Contact tab opens |
| Locate "Phone" section | Phone section is displayed in the Contact tab |
| Select a phone record from the Phone List | Phone record is selected |
| Click "Delete" button | Confirmation dialog "Delete Phone?" appears |
